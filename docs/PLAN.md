# DemonX Forge: plan and decisions

## What it is

A Fusion-style parametric 3D CAD application, local only, in the DemonX look. Not a launcher for someone else's program: the interface, the file handling and the command layer are ours; the modelling engine underneath is replaceable.

## Decisions

- **2026-10-18, owner: own repository, own product.** Apps that share code in one repository break each other. Forge shares the look (colour variables, dark and light, layout habits), not code, with DemonX CNC and Design.
- **2026-10-18, owner: no integration with DemonX CNC or Design.** Export files only (STEP, STL, DXF, SVG). Forge does not talk to their servers.
- **2026-10-18, owner: Fusion-style, not FreeCAD-style.** Browser tree, sketch then features, timeline, parameters. FreeCAD's workbench layout was tried and rejected.
- **2026-10-18, owner and Claude: clean room.** Public documentation and observed behaviour only. No reverse engineering of Autodesk Fusion or any proprietary CAD; no reading or converting its files. Open source (SolidCraft, MIT OR Apache-2.0) may be used under its licence.
- **2026-10-18, owner: name is DemonX Forge.** ("Mesh" was rejected: a mesh is only the display approximation of a solid.) Check for name clashes before publishing anywhere.
- **2026-10-18, owner and Claude: engine = SolidCraft's headless CLI behind our `Engine` interface** (React and Three.js interface of our own). Why: a spike (`docs/evaluation/SPIKE.md`) showed face picking, parameter edits and click-to-command in under half a second on a small part, and checks (`docs/evaluation/SOLIDCRAFT.md`) showed correct STEP/STL output verified by OpenCascade. Fallback: OpenCascade in WebAssembly or as a sidecar, if the kernel proves too weak on the owner's parts.
- **2026-10-18, owner and Claude: GPL-3.0-or-later**, same as DemonX, so code can move between them. The owner has no plan to sell it; this only keeps things simple.
- **2026-10-18, owner: follow Fusion's layout, menus and keys as closely as practical, for familiarity** (Solid and Sketch tabs, Create / Modify groups, browser tree, timeline strip, view cube, sketch palette; E extrude, L line, R rectangle, C circle, D dimension, H hole, Ctrl+Z / Ctrl+Y). Order of work: **sketch and extrude first.** Layout and shortcuts were taken from the owner's own screenshots of how they use Fusion (observed behaviour); icons, artwork and wording are ours, never copied.
- **2026-10-18, owner: Z is up** (the owner uses Z-up in Fusion too; the engine is Z-up). The TOP view looks down Z. No Y-up option is planned.
- **2026-10-18: our file is `.forge`: a zip holding `forge.json` (format `demonx-forge`, version, app version, engine, time) and `design.solidcraft` (the engine's own design container, which keeps the whole history).** Why: the container is the most faithful round trip the engine has, and our header makes the file ours and checkable (strict reader: a foreign, damaged or newer file is refused with the reason and nothing changes). If the engine is ever replaced, the version field is where a converter hooks in. Exports are STEP, STL (binary), 3MF, OBJ and a sketch as DXF (millimetres).
- **2026-10-18: work on `main` for the first commits** (empty repository), branches and PRs after that.

## Engine hand-over and the Windows package

- **2026-10-18: the Windows zip is built by GitHub Actions** (`.github/workflows/windows-package.yml`), like DemonX's: a Windows job compiles SolidCraft's `solidcraft-cli.exe` from the commit in `engine/SOLIDCRAFT_REF` (no debug info, stripped, so the file is much smaller than the 384 MB debug build used in the evaluation), runs a smoke test on it, then a Linux job bundles the server, the web app, its own Node, the engine and the engine's licence files into `DemonX-Forge-<version>-windows-x64.zip` (+ `.sha256`). A tag `v<version>` also attaches it to a release (notes in `docs/releases/`).
- The engine commit is pinned on purpose: SolidCraft changes daily and its command names are not stable. Change `engine/SOLIDCRAFT_REF` only after trying the new one.
- **Tried:** the packaging script on Linux (zip builds, Node download checked against its published checksum) and the bundled server run from the package folder against the real Linux engine with the full browser check (`e2e/viewport.mjs`, all passed). **Not tried:** the Windows engine build in CI, and the zip on a Windows PC. The first Windows build compiles the whole engine (expect 20 to 40 minutes; later runs use a cache) and may need fixing.
- Not in the package yet: auto-update (DemonX has it), a Start menu entry, code signing.

## Engine findings (keep adding)

- **A sketch on a face needs an exact pick:** `sketch.create` with `plane: {face: [x,y,z], body, index}`; the point and body alone are refused.
- **Center Rectangle also draws two construction diagonals** (as Fusion's does): 4 solid lines and 2 construction lines.
- **Keyboard focus:** a ticked checkbox must not block shortcuts (clicking Snap turned the L, R, C keys off until the next click). Only text boxes, lists and text areas own the keyboard.
- **A full circle extrudes to two half-cylinder faces** (`c1#1`, `c1#2`), so clicking a hole's wall picks half of it. To fix later by grouping faces that share a name before the `#`.
- **A cut goes along the sketch normal by default**, which for a sketch on a top face is away from the body (it removes nothing). Forge flips a Cut toward the body (using the body's centre), as Fusion does; a negative distance flips it back.
- **A second dimension on the same line is refused** (over-constrained). To change one, set its parameter (`d1`, `d2`, ...): the line follows. Forge's dimension tool does this when you click a dimensioned line.
- **Standard planes:** XY is x right, y up (normal +Z); XZ has sketch y pointing down the world's Z (normal +Y); YZ has x = world Y, y = world Z (normal +X). The camera's up vector follows the sketch's y axis, otherwise a sketch on XZ looks upside down.
- **Saving:** the engine's `save` writes a zip container (`PK`), `open` replaces the design, and `dirty` in `inspect_design` tracks unsaved changes correctly (true after edits, false after save, open or new). Opening a missing or junk file gives a clear error and leaves the design alone (tested). `export` writes step, stl (binary), stla (text), 3mf, 3mf-tagged, obj; `sketch.export_dxf` writes one sketch.
- **Editing:** `timeline.edit {feature, set}` changes a feature in place (one undo step): an extrude's `set` is `{extent: {distance, direction}, operation, profiles: {type: 'curves', loops: [[curve ids]]}}`, and the definition calls a new body `new_body` where the command says `new`. `sketch.edit {sketch}` reopens a sketch; `sketch.finish` rebuilds what depends on it. `timeline.roll_to {feature}` moves the history marker (`{}` goes to the end); `timeline.dependents` says what a delete takes with it (the sketch's extrudes, not the sketch itself).
- Origin planes overlap, so a click picks the nearest one under the pointer (the hover highlight shows which).

- **Face areas from `body_topology` are approximate.** The demo bracket's top face is exactly 2943.451 mm² (width 60) and 4943.451 (width 100), checked by OpenCascade on the exported STEP and by hand; the engine's face list says 2945.06 and 4946.21 (+0.05 to +0.06 %). Volumes and areas from its `measure` command and from the STEP are exact. So: use `measure` for any number shown as a dimension; the face list is for picking and display only. (Not yet checked whether `measure` gives the exact face area; do that before showing areas.)
- **Unknown parameters are silently ignored** by the engine; our adapter warns (`unknownParamNames`).
- **Edges:** `body_topology` edges are named `A|B` after the two faces they join (`A|B~k` when there are several); `solid.fillet`/`solid.chamfer` take `edges: [{body, index}]` and the blend follows edges that continue smoothly (a rounded corner carries round the outline: one pick gave +8 faces). Edge `length` is approximate. Forge draws an edge from the mesh boundary between two face ids, matched to the engine's edge by name pair and nearest midpoint (tested: all 30 edges of a rounded plate match within 1e-6). A too-big radius is refused with "the largest radius that fits is N mm".
- **A failed batch comes back as JSON** with `rolled_back: true`; the adapter turns it into a sentence and the design is unchanged (tested).

## What works now (0.14.3)

Fusion-style layout: SOLID tab with Create Sketch, Extrude (E), Hole (H); a SKETCH tab (only while a sketch is open) with CREATE (Line L, 2-Point Rectangle R, Center Rectangle, Center Circle C, 2-Point Circle, 3-Point Arc A, Slot), MODIFY (Trim T, Extend, Offset O, Fillet), CONSTRAINTS (Horizontal/Vertical, Coincident, Parallel, Perpendicular, Tangent, Equal, Midpoint, Concentric, Fix; Sketch Dimension D) and Finish Sketch; the browser tree (origin, bodies, sketches, parameters, with show/hide); an icon timeline; a view cube; a navigation bar; the sketch palette (grid, snap, profile fill).
Workflow: Create Sketch, pick an origin plane or a flat face, draw (snap to the grid and to existing points, a live outline while drawing, or type sizes), with no tool click a line to select it (Shift adds; Delete removes; X toggles construction), dimension (labels shown; click a dimensioned line again to change it), constrain, Finish Sketch (or press E: it finishes the sketch and opens Extrude), pick regions, set distance, direction and operation (new body, join, cut, intersect) with a **live preview** (applied to the real model and undone when anything changes or on Cancel). Undo and redo (Ctrl+Z, Ctrl+Y). Mouse as in Fusion: middle drag pans, Shift + middle orbits, wheel zooms toward the cursor. Unfinished picks are highlighted; construction geometry is dashed; fully constrained geometry turns to the text colour.
Tried in a real browser against the real engine: `e2e/sketch.mjs` (rectangle, circle, typed circle, dimension, change a dimension, E, preview, Cancel, OK, sketch on a face, cut, undo/redo, browser tree), `e2e/sketch2.mjs` (every tool in the second set: centre rectangle, arc, slot, 2-point circle, select / X / Delete / undo, Trim, Offset, Fillet, Horizontal, Parallel, Fix, a refused constraint) and `e2e/viewport.mjs` (demo part, picking, parameters, hole, view cube, mouse). Not tried: a Windows PC with this version, a touch or trackpad, sketches on curved faces, Extend, Coincident, Tangent, Equal, Midpoint (success), Concentric and Perpendicular through the browser (their steps are unit-tested only).
**Editing (0.4.0):** double-click a sketch in the timeline or the browser to reopen it (finish it and everything built on it rebuilds); double-click an extrude to open the dialog with its current regions, distance, direction and operation, with a live preview, Cancel and one undo step for the whole edit; right-click a timeline step for Edit, Rename, Suppress / Unsuppress, Roll history to here and Delete; the history marker shows when rolled back (later steps dimmed, a "Roll to end" button); Delete on a step warns what goes with it; Enter on a selected step edits it. `e2e/edit.mjs` covers all of it (26 checks).
**Files (0.5.0):** a File menu (New, Open, Save, Save As, Export) with Ctrl+O, Ctrl+S, Ctrl+Shift+S; the design has a name and an unsaved marker (●) in the header and the tab title, and closing the tab with unsaved work asks first; New and Open ask before discarding changes. In Chrome and Edge the real Open and Save windows are used and Save writes back to the same file (if the browser refuses to write back to an opened file, Save opens the Save window instead); other browsers get a download and a file chooser. Export: STEP, STL, 3MF, OBJ of the bodies, and each sketch as DXF. A file saved in the middle of a sketch keeps the unfinished sketch (it reopens as an ordinary sketch to continue). `e2e/files.mjs` covers both paths (39 checks). **Checked outside Forge:** an exported STEP read in OpenCascade is a valid solid with the exact volume (11214.602 mm³ against 11214.60 by hand), the STL is watertight (0.013 % off by tessellation), and the DXF opened in DemonX Design's own importer as exactly the circle and the closed outline.
**Fillet and Chamfer on bodies (0.6.0):** SOLID tab, MODIFY group (Fillet F, Chamfer). Hover an edge (amber), click to pick (click again to drop; one body at a time; edges hidden behind the part cannot be picked), set the size, live preview as for Extrude, OK or Cancel (Enter / Esc), one undo step. A refused size shows the engine's reason and keeps the dialog. `e2e/edges.mjs` covers it (picking, preview, refusal, Cancel, OK, undo/redo, chamfer, hidden edge). Fixed on the way: Cancel could leave a stray preview if a debounced preview fired during the undo (Extrude had the same race). Not tried: Windows PC, edges on curved or tangent-chained bodies beyond the rounded plate, variable radius.
**Press Pull (0.7.0):** Q or MODIFY, Press Pull. Click a face (or select one first, then press Q), type a distance: positive pulls the face out (adds material), negative pushes it in (removes it); live preview, OK / Cancel, one undo step; a distance of zero is not accepted. It uses the engine's `solid.press_pull` (face point + distance). `e2e/presspull.mjs` and `server/test/pressPull.test.ts` cover it. Not done: dragging the face with the mouse (Fusion's arrow), press/pull on a fillet's edges (the engine supports `edges` + distance: a radius change), pulling several faces at once, sloped faces. Not tried on a Windows PC.
**Shell and Revolve (0.8.0):** Shell (MODIFY): click the face(s) to leave open, type a wall thickness, live preview, refusal reason from the engine (a wall too thick: "the planes don't enclose a solid"). Revolve (CREATE): finish a sketch, press Revolve, pick profiles, choose the axis (sketch X or Y axis, any line of the sketch, or a world axis) and an angle up to 360; same dialog, preview and Cancel as Extrude; the form remembers the last axis. Editing a revolve from the timeline says plainly it is not available yet. `e2e/shell.mjs`, `e2e/revolve.mjs`, `server/test/revolve.test.ts`. Fixed: a late debounced preview after OK could add a second undo step (one `e2e/edit.mjs` run in four failed on it; eight in a row pass now). Not tried: Windows PC; revolve about a line that is not a straight sketch axis through the browser (line axes are in the dialog but only the sketch/world axes were exercised), shell direction outward/both, shell with no face (whole-body hollow).
**Mirror, patterns, Sweep and Loft (0.9.0):** CREATE group. *Mirror*: click the body (preselected when there is only one), choose the plane (YZ, XZ or XY through the origin), optionally join with the original. *Rectangular Pattern*: body, direction X/Y/Z, count (including the original), spacing (negative goes the other way), an optional second direction. *Circular Pattern*: body, world axis X/Y/Z, count, angle (360 spreads evenly). All three work on whole bodies, each copy is a new body, with live preview, OK / Cancel, one undo step. *Sweep*: pick the profile, choose another sketch as the path (its lines and arcs are put in order end to end by `web/src/chain.ts`). *Loft*: click one profile in each of two or more sketches, in order. Both share the Extrude dialog and operations. Tests: `e2e/patterns.mjs`, `e2e/sweeploft.mjs`, `server/test/copies.test.ts`, `web/src/chain.test.ts`. Not done: patterns or mirror of features (bodies only), mirror about a plane that is not through the origin or about a face, pattern along a path, sweep with a guide rail or a twist, loft with rails or tangency, sweep paths that are one circle or spline, editing any of these from the timeline. The sweep path starts at whichever free end comes first; checked with a straight line only, not with a bent path in the browser. Not tried on a Windows PC.
**Offset Face, Draft, Combine and DXF of a face (0.10.0):** MODIFY group. *Offset Face*: click flat faces (several allowed), type a distance (positive moves them out). *Draft*: click the wall faces, choose the neutral plane (bottom or top of the body, or the XY / XZ / YZ plane through the origin) and an angle; a positive angle narrows the part away from the neutral plane. Checked: a 5 degree draft on a 10 mm wall moves its far edge 0.87 mm (10 x tan 5), the neutral edge stays. A neutral plane picked from a face is not done. *Combine*: choose the target body, click the tool bodies (the second body is preselected when there are two), Join / Cut / Intersect, Keep tools. *DXF of a face*: select a flat face, File > Export > Selected face: the outline and any holes as DXF in millimetres, in the face's own plane coordinates; the engine projects the face's edges into a temporary sketch, exports it and takes it out of the design again (nothing is added to the timeline). **Checked outside Forge:** DemonX Design's own DXF importer reads the file as two closed shapes (outline and hole) with no warnings. Holes come out as two arcs. Tests: `e2e/modify2.mjs`, `e2e/facedxf.mjs`, `server/test/faceDxf.test.ts`, `server/test/copies.test.ts`. Not done: pocket and hole depths in the DXF (they are not in a flat outline), curved faces, a face of a rotated body in a standard orientation, section DXF, editing these from the timeline. Not tried on a Windows PC.
**Move / Copy, Split Body, Hole, Thread, Rib (0.11.0):** *Move / Copy* (MODIFY): body, X/Y/Z distance, optional turn about a world axis through the origin, Copy keeps the original. *Split Body* (MODIFY): body, an X/Y/Z plane at a position; a plane that misses the body is refused with the engine's reason. *Hole* (CREATE, H) is now a dialog with a live preview: click a face (or select one first), position X/Y/Z (filled from the click, editable), diameter, depth (empty = through), type simple / counterbore / countersink. **Editing a hole:** double-click it in the timeline (or right-click, Edit): the same dialog with its current numbers, applied in place with `timeline.edit` (an empty depth removes the depth; checked in the engine and in the browser). *Thread* (MODIFY): click a round wall (a flat face is refused), thread size (empty = the size that fits), length, Modeled; cosmetic by default (nothing changes in the shape; a Thread appears in the timeline); the engine refuses a size that does not fit ("an M20 thread does not fit a 10.00 mm hole"). *Rib* (CREATE): a wall grown from a line in a sketch (the sketch is chosen in the dialog; its lines are put in order by `chainOrder`), thickness, depth (the engine needs one: "give a depth"), Flip. Tests: `e2e/tools3.mjs`, `server/test/copies.test.ts`; `e2e/viewport.mjs` now drives the Hole dialog. Layout: the ribbon scrolls sideways when it is wider than the window. Dialogs sit over the top-left of the view, so click parts of the model outside the dialog. Not done: hole positions by dragging, holes from sketch points, tapped / clearance holes from a table, a hole's face changing, rib direction in/normal, split by a face or a sketch line, rotate about a point or an edge, editing the others of this batch from the timeline. Not tried on a Windows PC.
**STEP import, section DXF, editing from the timeline (0.12.0):** *File > Import STEP / IGES…* inserts the file as a new component (`file.insert_step`), it does not replace the design; the engine reads only files inside its own work folder, so the server writes the upload there first. A round trip (export STEP, import into an empty design) gave the same size and place; the imported plate has 7 faces (the hole is one round face, not two halves). A junk file is refused with the engine's reason ("not a STEP file (no ISO-10303-21 header)") and a wrong extension by name. Only STEP and IGES in the browser; FreeCAD and Rhino files are not offered. *File > Export > Section through a body…*: body, plane (XY / XZ / YZ) and position; the engine cuts the body with a temporary sketch plane (`sketch.fit_curves_to_section`), exports the lines and arcs as DXF with Z up for the front and side views, and the sketch is undone (it can take more than one undo step: the server undoes until it is gone). A section of an imported solid comes out as a few more pieces than a native one (it is cut as a mesh). **Editing a Fillet, Chamfer, Shell, Offset Face or Draft:** double-click it in the timeline (or Edit): a small dialog with the one number (radius, distance, thickness, angle) and a live preview; the edges or faces it was made on cannot be re-picked (delete and redo for that). Press Pull is an Extrude underneath (it adds a Sketch and an Extrude), so double-clicking that Extrude edits it. A refused number shows the engine's reason (a radius of 100: "the largest radius that fits is 30 mm"). Tests: `e2e/importsection.mjs`, `e2e/valueedit.mjs`, `server/test/importSection.test.ts`. Not done: STEP import with assemblies tested (only a single part), FreeCAD / Rhino files, a section at an angle or through several bodies, a section DXF with the cut face filled, editing Mirror / patterns / Combine / Move from the timeline. Not tried on a Windows PC.
**Scale, Coil, Pipe, Emboss and a drag arrow (0.13.0):** *Scale* (MODIFY): body, a factor (or uneven X / Y / Z factors), about the middle of the body or the origin. *Coil* (CREATE): made from numbers only, no body needed: diameter, section size (round or square), exactly two of turns / height / pitch (the dialog refuses all three or fewer than two; the engine itself would accept three), axis X/Y/Z, start point, new / join / cut. *Pipe* (CREATE): a round pipe along a path sketch (lines and arcs end to end), solid or with a wall. *Emboss* (CREATE): raise or cut in a sketch profile off the face it was drawn on, depth default 2 mm (a sketch on a face also projects the face's outline, so the circle is clicked as the profile). **Drag arrow:** Press Pull and Extrude show an arrow in the view; drag its tip along the arrow (0.5 mm steps, 0.1 with Shift) and the Distance box and the live preview follow; typing moves the arrow; dragging past the face gives a negative distance (pushes in / cuts). The arrow follows a Cut's automatic direction. The arrow's size is set when it is drawn, so it does not rescale if you zoom while it is open. Tests: `e2e/shapes.mjs`, `e2e/drag.mjs`, `server/test/copies.test.ts`. Not done: dragging for other tools (fillet radius, hole position), the arrow on Revolve / Sweep, a text or logo emboss from fonts, coil on a plane or face picked in the view. Not tried on a Windows PC or with a touch screen.

**Offset follows the mouse (0.13.2):** the sketch Offset tool (O) no longer asks for a number in a prompt. Click the curve, then move the mouse: an amber preview of the offset curve and an Offset box (the distance, to 0.1) follow the pointer; a click places it, or type a number (digits, or Tab, go to the box) and press Enter; Esc cancels. The preview shows the picked curve only (lines and circles); with `chain: true` the engine may also offset connected curves, so the result can be longer than the preview. Offset Face (solid) now shows the same drag arrow as Press Pull. Not done: previews for arcs and chains, a drag arrow for Draft angle and Shell thickness.
**Second round of fixes from the owner's test (0.14.0):** (1) *Size boxes are on the shape.* The width and height (or diameter, or length and angle) are real input boxes sitting on the edges of the shape being drawn, as in Fusion; the bottom panel is gone. (3) *Right-click menu* in the view: with a shape selected the Extrude family, with a face selected Press Pull / Hole / Offset Face / Draft / Shell / Thread / Create Sketch on the face / Export face DXF, in a sketch the sketch tools and Finish Sketch, and always Undo / Redo / Keyboard shortcuts. **Size boxes for arcs and slots (0.14.1):** a 3-point arc shows Length and Angle for its chord (start to end), then one Radius box; a slot shows Length and Angle between its two centres, then one Width box. Typing fixes the value and the preview follows; Tab, Enter and clicking place it as for the other shapes. A radius smaller than half the chord cannot reach and is ignored (the pointer decides); the long way round is chosen by moving the pointer past the middle of the circle. The placed arc's radius can be a thousandth off (the through point is rounded to 0.001 mm). `web/src/sketch/sizes.test.ts` and `e2e/drawing.mjs` cover it. The drawing code now has one function (`sizeBoxes` in `sketch/tools.ts`) that says for each tool and stage what the boxes are called, where they sit and what the pointer gives them. Not done: boxes for polygons, ellipses, splines (those tools do not exist yet) and for the construction of Fillet / Offset values (Offset has its own box).
**Selecting in an open sketch, moving, and a 0-start Extrude (0.14.2, from the owner's test of 0.14.0):** (1) *In an open sketch with no tool* a shape (closed region) under the pointer lights up and a click selects it (stays lit); a click on a curve still selects the curve; a plain click replaces the selection, Shift or Ctrl adds or removes one; the same in the model view. (2) *Moving sketch geometry:* with no tool, press on a point or curve and drag; it is sent to the engine's `sketch.drag` (a point goes where you drag, a line slides, a circle dragged by its edge changes size: drag its centre point to move it). (3) *Extrude, Press Pull and Offset Face start at 0* (not at the last number); nothing is previewed until you drag the arrow or type; the arrow has a number box beside it that shows the live distance, accepts a typed number, and Enter in it accepts the dialog.
