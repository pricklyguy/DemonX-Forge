# DemonX Forge 0.14.3

Sizes on the sketch.

- **Dimensions check box** in the Sketch Palette (on by default): the sketch shows the size of its lines (a rectangle shows width and height), the diameter of its circles and the radius of its arcs.
- **Double-click a size to change it:** the number opens in place; type the new value and press Enter and the sketch follows. A size you set this way becomes a real dimension that keeps the shape that size. Esc cancels, Ctrl+Z undoes.
- Untick Dimensions to hide all of them.

**Not there yet:** angles, distances between two points, Fusion-style dimension lines with arrows, dragging a label.
**Tested:** unit tests (93) and twenty-one real-browser checks against the real engine on Linux, including changing a rectangle from 100 to 120 to 90 and a circle from 12 to 25 by double-clicking. **Not tested:** the Windows zip on a Windows PC.

Download `DemonX-Forge-0.14.3-windows-x64.zip`, extract it to `C:\`, run `Start DemonX Forge.bat`.
