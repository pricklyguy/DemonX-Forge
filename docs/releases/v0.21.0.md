# DemonX Forge 0.21.0

More sketch dimensions: angles, and distances between points.

- **Angle between two lines.** Press D, click one line (the length box opens), then click a second line instead: the box asks for the angle in degrees, starting at the measured one. The lines turn to it. The label reads like `45°` and you can double-click it to change it later.
- **Distance between two points.** With the Dimension tool, click two points (line ends, circle centres). The box has a choice of Aligned (straight between them), Horizontal or Vertical, and the number follows the choice.
- **Distance from a point to a line.** Click a point, then a line (or the other way round).
- Circles, arcs and single lines work as before (click one and type its size). Clicking right on a line's end now picks the end point; click along the line to size the line.
- **Fix: Check now stayed grey after an update.** After Forge updated itself, the "Updated from X to Y" note was treated as an update still in progress, which disabled Check now until Forge was restarted again (and the window kept polling every second). It is now just a note.
- **Fix: MCP "Connection closed" on an installed-then-updated Forge.** Update now only replaced the version folder, never the `launcher.mjs` beside it, so an install that began before 0.19 kept a launcher that does not know `mcp`. Each version now carries the start files and puts changed ones in place when it starts (not the start `.bat` itself). **An install that is already old needs one manual step**: extract the new zip over `C:\DemonX-Forge` (or copy `launcher.mjs` from it); after that it keeps itself current. `docs/MCP.md` also fixes the `claude mcp add` order (`--scope user` before the name) and the Microsoft Store location of Claude Desktop's config.

**Tested:** the real engine and a real browser (`e2e/dimensions2.mjs`: angle, change by double-click, horizontal distance; the older sketch and dimension checks still pass), unit tests for the drawing geometry. **Not tested:** distances measured from the origin point (not offered yet), vertical and point-to-line distances in the browser (the code paths are the same as the horizontal one), dimensions on a sketch on a face.
