# DemonX Forge 0.9.0

Mirror, patterns, Sweep and Loft.

- **Mirror:** copy a body across the YZ, XZ or XY plane (through the origin), optionally joining the copy to the original.
- **Rectangular Pattern:** repeat a body along X, Y or Z, with a count (the original included) and a spacing; add a second direction for a grid. A negative spacing goes the other way.
- **Circular Pattern:** repeat a body round the X, Y or Z axis with a count and an angle (360 spreads the copies evenly).
- **Sweep:** carry a profile along a path drawn in another sketch (lines and arcs joined end to end).
- **Loft:** click one profile in each of two or more sketches, in order; the solid passes through them.
- All of them have a live preview, OK / Cancel (Enter / Esc) and one undo step. Sweep and Loft use the Extrude dialog, so new body, join, cut and intersect work as before.

**Not there yet:** patterns of features (bodies only), pattern along a path, sweep with a guide rail or twist, loft with rails, editing these from the timeline, dragging for press/pull, DXF of a face, STEP import.
**Tested:** unit tests (79) and eleven real-browser checks against the real engine on Linux. **Not tested:** the Windows zip on a Windows PC; a sweep along a bent path in the browser.

Download `DemonX-Forge-0.9.0-windows-x64.zip`, extract it to `C:\`, run `Start DemonX Forge.bat`.
