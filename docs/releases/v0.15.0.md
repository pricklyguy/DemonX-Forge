# DemonX Forge 0.15.0

Update now, like DemonX CNC and Design.

- **Update check:** Forge asks GitHub's public release list about once a day (and at start). When a newer release exists the header shows a green **Update 0.x.y** button; File > Updates... opens the same window. It shows what is new and when it last checked. Untick **Check for updates** to stop it (it is the only thing Forge sends to the internet). **Skip this version** hides the button for one version.
- **Update now (Windows package):** tick **Allow Update now** (off until you turn it on), save your design, press **Update now**. Forge downloads the new Windows zip, checks it against the checksum published with the release, unpacks it beside the running version, then restarts into it; the page reloads by itself. If the new version does not start, the old one is put back and Forge says so. It will not restart while the design has unsaved changes, because the design lives in the running engine.
- **New folder layout:** each version has its own folder (`versions\<number>\app` and `engine`), `current.txt` says which runs, and `launcher.mjs` starts it. Extract the 0.15.0 zip over an older install as before; the old `app` and `engine` folders are removed at the first start.

**Not there yet:** a test-release channel switch (it follows test releases only when the running version is one), update progress as a percentage in the header, updating anything but the Windows package.
**Tested:** unit tests (the updater against a local stand-in for GitHub's downloads with real zip files, the launcher as a real program, the release-list parsing and version order, the saved settings), the real 0.15.0 zip through the real updater (download, checksum, unpack, layout check, switch), and a real-browser check of the window against a stand-in release list (`e2e/updates.mjs`). **Not tested:** Update now on a Windows PC (it needs the Windows package and `tar.exe`), a real GitHub release, the Windows zip.

Because earlier versions cannot update themselves, 0.15.0 itself has to be installed from the zip once. After that the next release can be installed with Update now.

Download `DemonX-Forge-0.15.0-windows-x64.zip`, extract it to `C:\`, run `Start DemonX Forge.bat`.
