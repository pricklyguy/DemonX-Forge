# DemonX Forge 0.13.2

Offset follows the mouse.

- **Sketch Offset (O):** click the curve, then move the mouse. A preview of the offset curve and the distance follow the pointer; click to place it, or type a distance and press Enter. Esc cancels.
- **Offset Face:** now has the same drag arrow as Press Pull and Extrude.

**Not there yet:** the preview of an offset arc or a connected chain (the result is still correct, the preview shows only the picked line or circle), arrows for Draft and Shell.
**Tested:** unit tests (84) and real-browser checks against the real engine on Linux, including moving the mouse to set the distance and clicking to place it. **Not tested:** the Windows zip on a Windows PC.

Download `DemonX-Forge-0.13.2-windows-x64.zip`, extract it to `C:\`, run `Start DemonX Forge.bat`.
