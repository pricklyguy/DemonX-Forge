# DemonX Forge 0.12.0

STEP import, section DXF, and editing from the timeline.

- **Import STEP / IGES** (File menu): adds a part made elsewhere as a new component. Your design is kept. A file that is not a STEP file is refused with the reason.
- **Section through a body** (File > Export): choose the body, the plane (XY, XZ or YZ) and where to cut, and get the outline of the cut as a DXF of lines and arcs in millimetres, standing up (Z up) for the front and side views. Ready for DemonX Design. Nothing is added to your design.
- **Edit from the timeline:** double-click a Fillet, Chamfer, Shell, Offset Face or Draft to change its radius, distance, thickness or angle, with a live preview. Press Pull is an Extrude underneath, so double-click that Extrude. (Holes and extrudes could already be edited.)

**Not there yet:** re-picking the edges or faces of an existing fillet, editing mirror / patterns / combine / move, FreeCAD and Rhino files, scale, coil, pipe, emboss, dragging for press/pull and extrude.
**Tested:** unit tests (83) and sixteen real-browser checks against the real engine on Linux. A STEP file made by Forge came back in with the same size and place. **Not tested:** the Windows zip on a Windows PC; assemblies and files from other CAD programs.

Download `DemonX-Forge-0.12.0-windows-x64.zip`, extract it to `C:\`, run `Start DemonX Forge.bat`.
