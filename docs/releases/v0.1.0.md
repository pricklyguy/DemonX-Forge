# DemonX Forge 0.1.0 (first test build)

The skeleton: browser interface in the DemonX look, a 3D view with face picking, a parameter list, a timeline strip, a demo bracket, undo and redo. Modelling is done by SolidCraft's engine, included in the zip with its licences.

**Not there yet:** sketch tools, a file menu, save and open, export, a timeline you can edit.
**Tested:** unit tests, tests against the real engine, and a real-browser check on Linux. **Not tested:** this Windows zip on a Windows PC.

Download `DemonX-Forge-0.1.0-windows-x64.zip`, extract it to `C:\`, run `Start DemonX Forge.bat`. See `READ ME FIRST.txt` inside.
