# DemonX Forge 0.23.0

A drag arrow for Fillet and Chamfer, a ribbon laid out like Fusion's, and drawing that stays open after a drag.

- **Drag the radius.** With Fillet (or Chamfer) open and an edge picked, an arrow sits on the first picked edge and points into the material. Drag it: the Radius (or Distance) box follows and the live preview rounds the edge as you go; release to keep the value, then OK. Typing a number still works the same way.
- Not shown for a step you are editing from the timeline (only its number can change there), or for an edge between two faces the engine does not name (a seam).
- **Ribbon like Fusion's.** The SOLID tab has the groups CREATE, MODIFY, then INSPECT (Measure, Section to DXF) and INSERT (Import) on the right, and each group title (`CREATE ▾`) opens a menu listing its commands. INSPECT and INSERT are no longer tabs; the 0.22.0 ones also wrongly showed the Modify group on all three tabs. There is a new MESH tab (Insert Mesh, Mesh to Solid, Scale). SURFACE, SHEET METAL and the other Fusion tabs are not here because there is nothing behind them.
- **Drag to draw stays open.** Press, drag and release with Rectangle, Center Rectangle, Center Circle or 2-Point Circle: the shape stays open under the pointer, with its size boxes, so you can still change the size (move, or type a number) and a click finishes it. Line, Arc and Slot behave as before.
- **Fix: the Offset box could not be emptied.** Deleting the first digit you typed brought the live distance back, so you could not type a different number. The box now keeps what you type, even nothing.

**Tested:** the real engine and a real browser (`e2e/polish.mjs`: pick an edge, F, the arrow is there with value 2, dragging it outward makes the radius 5, the preview still shows the rounded edge, OK keeps one step; `edges`, `modify2`, `drag` still pass), a unit test for the arrow's direction. **Not tested:** the narrow-window wrapping of the new ribbon on Windows, Chamfer's arrow in the browser (same code path), a concave edge, a round edge (the arrow points along the average of the two face normals there), Windows.
