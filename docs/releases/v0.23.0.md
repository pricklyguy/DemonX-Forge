# DemonX Forge 0.23.0

A drag arrow for Fillet and Chamfer.

- **Drag the radius.** With Fillet (or Chamfer) open and an edge picked, an arrow sits on the first picked edge and points into the material. Drag it: the Radius (or Distance) box follows and the live preview rounds the edge as you go; release to keep the value, then OK. Typing a number still works the same way.
- Not shown for a step you are editing from the timeline (only its number can change there), or for an edge between two faces the engine does not name (a seam).

**Tested:** the real engine and a real browser (`e2e/polish.mjs`: pick an edge, F, the arrow is there with value 2, dragging it outward makes the radius 5, the preview still shows the rounded edge, OK keeps one step; `edges`, `modify2`, `drag` still pass), a unit test for the arrow's direction. **Not tested:** Chamfer's arrow in the browser (same code path), a concave edge, a round edge (the arrow points along the average of the two face normals there), Windows.
