# DemonX Forge 0.20.0

A launch point on the desktop, starting at login, and a Linux package.

- **Windows: a desktop icon.** Double-click `Create Desktop Shortcut.bat` once; a DemonX Forge icon appears on your desktop and starts Forge (a shortcut to `Start DemonX Forge.bat`, with the Forge icon).
- **Windows: start at login.** `Start at login.bat` makes Forge start by itself, minimised, when you sign in, and asks whether it should also open the browser (Y for a computer you sit at, N to run in the background and open it from the desktop icon). `Stop starting at login.bat` undoes it. `Start DemonX Forge.bat nobrowser` starts it without the browser.
- **Linux package.** `DemonX-Forge-<version>-linux-x64.tar.gz`: Forge, its own Node and the engine (built on Ubuntu 22.04, so it runs on older systems), nothing to install. `./start-forge.sh` starts it and opens the browser. `./install-launcher.sh` adds an applications-menu entry and a desktop icon and, if you say yes, starts Forge at login (`./uninstall-launcher.sh` undoes it). The step-by-step guide is `docs/LINUX.md`, also in the package as `READ ME FIRST.txt`.
- **Updates on Linux** are by hand for now: the Update button opens the release notes and the window says to extract the new package over the old folder. (Update now works on Windows only.)

**Tested:** the Linux package built here and started from the extracted tar.gz with the real engine (it answered and built a part); the menu, desktop icon and login entries with a throwaway home folder (unit tests); the launcher on Linux. **Not tested:** the GitHub Actions jobs that build the Linux engine and package (they are new and have not run yet: run the workflow by hand and look), the Windows batch files on Windows (they follow DemonX's `Start at login.bat`), a real Linux desktop (GNOME's "Allow Launching" step, KDE).

Download `DemonX-Forge-0.20.0-windows-x64.zip` (extract to `C:\`, run `Start DemonX Forge.bat`) or the Linux tar.gz.
