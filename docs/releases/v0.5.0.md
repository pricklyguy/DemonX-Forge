# DemonX Forge 0.5.0

Save, open and export.

- **File menu:** New, Open, Save, Save As, Export. Ctrl+S, Ctrl+Shift+S, Ctrl+O.
- **.forge files** keep the whole history, so a reopened design is fully editable (reopen a sketch, change a dimension, the part follows).
- The design has a **name** and an **unsaved marker** (●) in the header and the tab title. Closing the tab with unsaved work asks first; New and Open ask before discarding changes.
- **Chrome and Edge** use the normal Windows Open and Save windows, and Save writes back to the same file. Other browsers download the file and use a file chooser.
- **Export:** STEP, STL, 3MF and OBJ of the bodies, and any sketch as DXF (millimetres), for DemonX Design or another program. A STEP file made this way reads in OpenCascade as a valid solid with the exact volume; the DXF opens in DemonX Design.
- A file saved in the middle of a sketch keeps the unfinished sketch.

**Not there yet:** DXF of a face or a section of a body, STEP import, recent files, autosave, fillet and chamfer on bodies.
**Tested:** unit tests (60) and five real-browser checks against the real engine on Linux. **Not tested:** this Windows zip on a Windows PC, and the real Chrome file windows (a stand-in was used).

Download `DemonX-Forge-0.5.0-windows-x64.zip`, extract it to `C:\`, run `Start DemonX Forge.bat`. See `READ ME FIRST.txt` inside.
