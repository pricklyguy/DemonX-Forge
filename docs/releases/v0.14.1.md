# DemonX Forge 0.14.1

Size boxes for arcs and slots.

- **3-point arc:** after the start point, boxes for the Length and Angle of the chord; after the end point, one Radius box. Type a value to fix it, move the mouse to choose which side the arc bulges (and move past the middle of the circle for the long way round).
- **Slot:** boxes for the Length and Angle between the two centres, then one Width box.
- Tab moves between the boxes and Enter (or a click) places the shape, as for rectangles and circles.

**Not there yet:** polygons, ellipses and splines (the tools themselves are still to come).
**Tested:** unit tests (93) and real-browser checks against the real engine on Linux, including typing a radius and a width. **Not tested:** the Windows zip on a Windows PC.

Download `DemonX-Forge-0.14.1-windows-x64.zip`, extract it to `C:\`, run `Start DemonX Forge.bat`.
