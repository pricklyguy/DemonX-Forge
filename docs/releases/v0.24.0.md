# DemonX Forge 0.24.0

A tidier ribbon, a clearer sketch-plane picker, sketch grid and axes switches, and save by clicking the document name. This work came from the `codex/compact-ribbon-plane-picker` branch.

- **Compact ribbon.** Each group shows only its main commands (Create Sketch, Extrude, Revolve; Fillet, Chamfer; Measure; Import; the MESH tools). Everything else is one click away in the group's `▾` menu. In a narrow window the bar hides buttons from the right instead of wrapping onto a second row.
- **Sketch plane picker.** Create Sketch shows a "Select sketch plane" panel (XY / Top, XZ / Front, YZ / Side, Cancel). The planes are fainter, labelled in the view, and the one under the pointer lights up. The same three planes can be picked from Origin in the browser tree.
- **Grid and axes.** The grid and the axes are separate switches (navigation bar and Sketch Palette). The grid choice is remembered.
- **Save from the name.** Click the document name in the header to save (the same as Ctrl+S).

**Tested:** typecheck, unit tests and the whole `e2e/` suite in a real browser with the real engine. The e2e checks now open a group's menu to reach commands that are no longer pinned (`e2e/menu.mjs`), and the 1000 px window check looks at the pinned buttons and group menus. **Not tested:** Windows, a real narrow window by hand.
