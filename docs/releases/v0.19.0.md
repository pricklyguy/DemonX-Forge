# DemonX Forge 0.19.0

The version in the header, and an MCP server so an AI can use Forge.

- **The running version is shown in the header** (small grey `v0.19.0` at the top right, next to the Update button). Click it for the Updates window.
- **MCP server.** An AI program that speaks MCP (Claude Desktop, Claude Code, OpenAI's Codex, the OpenAI Agents SDK) can start `node\node.exe launcher.mjs mcp` and then: read the open design, list the modelling commands, run them, measure, take a screenshot, change a parameter, undo and redo. Nine tools, all going through the same checked routes as the buttons; it cannot open, save, export or delete files.
- **The window follows the AI.** Forge's page checks every two seconds whether the design was changed by another program and refreshes when you are not in a dialog, a sketch or an extrude (a notice says another program changed it).
- **How to connect them:** `docs/MCP.md`, also in the zip as `CONNECT AN AI (MCP).txt`: Claude Desktop (config file), Claude Code (`claude mcp add`), Codex (`codex mcp add` or `config.toml`), the Agents SDK (Python), and why Claude on the web and ChatGPT cannot be used (they need a public https server; Forge is local only on purpose).

**Tested:** the protocol and every tool against a stand-in Forge (unit tests, and the launcher's MCP mode as a real program), and the whole thing in a real browser with the real engine and a real bridge process (`e2e/mcp.mjs`): the AI builds a block with a hole and the open window shows it by itself, faces and edges, commands, measure, a PNG screenshot, a fillet and its undo, a file command refused. **Not tested:** Claude Desktop, Claude Code, Codex or the Agents SDK themselves (the steps follow their documentation), Windows paths.
