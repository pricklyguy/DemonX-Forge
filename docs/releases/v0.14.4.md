# DemonX Forge 0.14.4

Usability fixes from testing 0.14.3.

- **E on a body face:** select a face of a body, press E (or click Extrude), and it pushes or pulls that face (Press Pull), as in Fusion.
- **Move / Copy redone:** M (or the ribbon, or right-click) opens a small dialog. Move is the default; tick Copy to make a moved copy instead. Three coloured arrows (X red, Y green, Z blue) sit on the body: drag one, or type in its box. In the dialog, pick a **step** (0.1 to 100 mm) and use the − / + buttons beside X, Y and Z; Turn about has − / + in 15° steps. A single body is chosen for you.
- **Every command can be reached with the mouse:** the ribbon now wraps onto a second row when the window is narrow instead of hiding buttons off the edge, and the right-click menu in the model view has a Modify section (Move / Copy, Split Body, Combine, Scale, Mirror, patterns, Shell, Press Pull, Hole, Coil) and a More create section (Revolve, Sweep, Loft, Rib, Pipe, Emboss).
- **Rubber band in a sketch:** drag over empty space with no tool. Left to right selects the curves wholly inside the box (solid outline); right to left selects every curve the box touches (dashed outline). Shift or Ctrl adds. Dragging no longer highlights the page text.
- **Snap hints while drawing:** the pointer snaps to line ends and centres (square), crossings (cross), midpoints (triangle), and aligns with other points or with the start of the shape you are drawing (a thin line shows what you are aligned to).

**Not there yet:** rotation rings on the Move arrows (turning is in the dialog), tangent / perpendicular hints, a tooltip naming the snap, snapping to a circle's quadrant points.
**Tested:** unit tests (middle, crossing, line-circle crossing, alignment, rubber-band box) and a new real-browser check (`e2e/usability.mjs`) against the real engine on Linux. **Not tested:** the Windows zip on a Windows PC.

Download `DemonX-Forge-0.14.4-windows-x64.zip`, extract it to `C:\`, run `Start DemonX Forge.bat`.
