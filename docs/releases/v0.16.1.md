# DemonX Forge 0.16.1

Fixes from testing 0.16.0.

- **Offset moves the whole outline.** Click one side of a shape (or a chain of lines) and the pointer side decides inside or outside: every connected side moves, with the corners mitred. The preview shows the whole new outline (it had stopped drawing at all since 0.14.0; it is back). A typed distance goes the way the pointer is; a negative number goes the other way. Chains that include arcs are done exactly by the engine (the preview then shows only the clicked curve).
- **Importing a mesh asks where to put it.** An STL, OBJ or 3MF file carries its own coordinates, so a bar now says where the file put it and offers "Centre it on the origin, on the floor" (the part's middle on X 0, Y 0 and its bottom at Z 0) or "Keep that position".
- **Move arrows stay with the part.** While you move a body the three arrows travel with it (they used to stay where the body started, with a long line to it). Dragging works as before.

**Tested:** unit tests for the outline walking and mitring, the real engine for the whole-outline offset (inside and outside), and real-browser checks (`e2e/offset.mjs`, `e2e/meshimport.mjs`). **Not tested:** Windows.
