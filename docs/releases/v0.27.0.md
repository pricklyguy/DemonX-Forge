# DemonX Forge 0.27.0

The modelling engine is now SolidCraft v0.19.0 (it was about v0.15). Nothing in Forge's own screens changed.

- **Newer engine.** The Windows package builds its engine from the v0.19.0 source (`engine/SOLIDCRAFT_REF`). This is the version of the full SolidCraft app that handled the face 0.25.0 could not sketch on ("this face can't keep an attachment"). Forge still falls back to an unattached sketch on that plane if the engine ever refuses a face again (0.26.0).
- A saved design from an earlier Forge opens the same; open one and check it before you rely on it for anything you care about.

**Tested:** all unit tests (157, including the ones that need the engine) and all 31 browser checks against the v0.19.0 engine, then the Package workflow on the branch, whose zip the owner ran by hand with no errors. **Not tested:** older saved designs from every earlier version.
