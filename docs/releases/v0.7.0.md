# DemonX Forge 0.7.0

Press Pull.

- **Press Pull (Q)** in the SOLID tab, MODIFY group. Click a face (or select one first and press Q), type a distance: positive pulls the face out and adds material, negative pushes it in and removes material. The part shows the result while you type. OK or Enter keeps it, Cancel or Esc removes it. One undo step.
- A distance of zero is not accepted, and a refused step shows the engine's reason and leaves the part alone.

**Not there yet:** dragging a face with the mouse, press/pull on a fillet (change its radius), shell, revolve, patterns, editing a press pull from the timeline, DXF of a face, STEP import.
**Tested:** unit tests (70) and seven real-browser checks against the real engine on Linux. **Not tested:** the Windows zip on a Windows PC.

Download `DemonX-Forge-0.7.0-windows-x64.zip`, extract it to `C:\`, run `Start DemonX Forge.bat`.
