# DemonX Forge 0.22.0

Fusion habits: edges first then Fillet, type right after E, drag to draw with a live shape, a Measure tool, and INSPECT / INSERT tabs.

- **Drag to draw shows the shape.** Press, drag and release with Rectangle, Circle and the other drawing tools: the shape (and its size boxes) follows the pointer while the button is down, and stays on screen until it is made. Before, nothing showed until a second after you let go.
- **Edges first, then Fillet.** In the model view the edge under the pointer lights up; click it (Shift or Ctrl adds more), then press F or the Fillet / Chamfer button: the dialog opens with those edges already chosen and the live preview showing. Clicking a face or empty space clears the edges. Picking Fillet first still works as before.
- **Type a number right after E (or F, Q, M...).** The first digit goes into the dialog's main box (Distance, Radius...), replacing what is there: no click needed.
- **Measure (INSPECT tab, or the I key).** Click a point (the end of an edge), an edge or a face; a second click measures between the two: distance and the X / Y / Z offsets between points, the length of an edge (diameter and radius of a round one), the area of a face (diameter of a round hole), the distance and angle between flat faces, between edges, from a point to a face or edge, and the distance between the axes of two parallel holes. A third click starts again; Esc closes.
- **Tabs.** SOLID (everything as before), INSPECT (Measure, Section to DXF), INSERT (Import, Mesh to Solid).
- **Fix: MCP "Connection closed" on an installed-then-updated Forge.** Update now only replaced the version folder, never the `launcher.mjs` beside it, so an install that began before 0.19 kept a launcher that does not know `mcp`. Each version now carries the start files and puts changed ones in place when it starts (not the start `.bat` itself). **An install that is already old needs one manual step**: extract the new zip over `C:\DemonX-Forge` (or copy `launcher.mjs` from it); after that it keeps itself current. `docs/MCP.md` also fixes the `claude mcp add` order (`--scope user` before the name) and the Microsoft Store location of Claude Desktop's config.

**Tested:** the real engine and a real browser: `e2e/polish.mjs` (drag draw, typing after E, edge then F with the live preview, typing the radius) and `e2e/measure.mjs` (tabs, point to point, an edge, two faces, Esc, the I key), unit tests for the Measure arithmetic; the older browser checks still pass. **Not tested:** the Windows machine, touch screens; Measure on a curved body (curved faces report area and diameter only), measuring a mesh body (it has no edges or faces to pick).
