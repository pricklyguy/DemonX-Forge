# DemonX Forge 0.3.0

More sketch tools, laid out like Fusion's SKETCH tab.

- **Create:** center rectangle, 2-point circle, 3-point arc (A), slot (with typed sizes where they make sense).
- **Modify:** trim (T), extend, offset (O), fillet.
- **Constraints:** horizontal/vertical, coincident, parallel, perpendicular, tangent, equal, midpoint, concentric, fix.
- **Select:** with no tool, click a line to select it (Shift adds). Delete removes it, X toggles construction (dashed).
- Clicking a checkbox in the palette no longer turns the keyboard shortcuts off.

**Not there yet:** editing an old sketch or feature from the timeline (next), polygon, ellipse, spline, mirror, patterns, fillet and chamfer on bodies, save, open and export.
**Tested:** unit tests (41) and three real-browser checks against the real engine on Linux. **Not tested:** this Windows zip on a Windows PC.

Download `DemonX-Forge-0.3.0-windows-x64.zip`, extract it to `C:\`, run `Start DemonX Forge.bat`. See `READ ME FIRST.txt` inside.
