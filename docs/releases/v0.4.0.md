# DemonX Forge 0.4.0

Editing, as in Fusion's timeline.

- **Double-click a step** in the timeline to edit it. A sketch reopens (and everything built on it rebuilds when you finish); an extrude opens its dialog with its current values and a live preview. Cancel puts it back; OK is one undo step.
- Double-click a sketch in the **browser** to reopen it too. **Enter** on a selected step edits it.
- **Right-click** a step: Edit, Rename, Suppress / Unsuppress, Roll history to here, Delete.
- **Roll history:** the marker shows where you are; later steps are dimmed; "Roll to end" brings everything back.
- **Delete** a step with Delete or the menu. If other steps depend on it, Forge says which first; undo brings them back.
- The extrude dialog has "One Side (reversed)".

**Not there yet:** editing a hole (delete it and make it again), dragging the marker or steps, save, open, export, fillet and chamfer on bodies.
**Tested:** unit tests (48) and four real-browser checks against the real engine on Linux. **Not tested:** this Windows zip on a Windows PC.

Download `DemonX-Forge-0.4.0-windows-x64.zip`, extract it to `C:\`, run `Start DemonX Forge.bat`. See `READ ME FIRST.txt` inside.
