# DemonX Forge 0.14.2

Selecting and moving in a sketch, and an Extrude that starts at zero.

- **Select in an open sketch:** with no tool, move the mouse over a shape and it lights up; click to select it. A plain click selects just that shape; hold Shift or Ctrl to add more. Then press E.
- **Move sketch objects:** press on a point, line or circle and drag. A line slides, a corner moves, and a circle moves when you drag its centre (dragging its edge changes its size). One Ctrl+Z undoes the whole drag.
- **Extrude starts at 0.00:** no more leftover number from last time. Drag the arrow or type a distance; the solid follows live. The arrow now has a number box beside it that shows the distance as you drag, accepts a typed number, and Enter accepts. Press Pull and Offset Face start at 0 as well.
- **M** opens Move / Copy (it moves by default; tick Copy to make a copy instead).

**Not there yet:** moving several selected curves at once, a free-move arrow for Move / Copy.
**Tested:** unit tests (93) and twenty real-browser checks against the real engine on Linux, including mouse drags in a sketch. **Not tested:** the Windows zip on a Windows PC.

Download `DemonX-Forge-0.14.2-windows-x64.zip`, extract it to `C:\`, run `Start DemonX Forge.bat`.
