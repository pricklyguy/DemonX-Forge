# DemonX Forge 0.16.0

STL import and Mesh to Solid.

- **Import STL, OBJ and 3MF** (File > Import STEP / IGES / STL...): the file becomes a mesh body in a new component, named after the file. A mesh is read in millimetres with Z up (an STL carries no units).
- **What a mesh can do:** move (M, with the arrows), scale, mirror, measure and export. It has no real faces or edges, so fillet, press pull, shell, split and the like are refused until it is converted.
- **Mesh to Solid** (MODIFY tab, or right-click): click the mesh (the only one is chosen for you), check the tolerance (0.05 mm), OK. The mesh is rebuilt as real planar and round faces, as a step in the timeline: Ctrl+Z gives the mesh back, and the result can be filleted, press-pulled, drilled and split.
- **Its limit:** the converter is the modelling engine's, and it rebuilds **closed meshes of mechanical parts with a constant cross-section** (plates, brackets, blocks with holes, tubes). A sculpted or organic mesh, or a part that changes section along its length (the demo bracket exported as STL is one), is refused with the engine's reason, and nothing is changed. A converter for any shape is not something the engine has.

**Tested:** a plate with a hole exported as STL, imported, converted (8 faces, 18 edges), undone, redone and filleted; the demo bracket and a junk file refused; all in a real browser against the real engine (`e2e/meshimport.mjs`). **Not tested:** large scans (a mesh of hundreds of thousands of triangles), OBJ and 3MF files from other programs, the Windows zip on a Windows PC.

Download `DemonX-Forge-0.16.0-windows-x64.zip`, extract it to `C:\`, run `Start DemonX Forge.bat` (or use Update now from 0.15.0).
