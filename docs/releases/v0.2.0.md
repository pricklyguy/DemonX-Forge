# DemonX Forge 0.2.0

Sketch and extrude, laid out like Fusion: SOLID and SKETCH tabs, browser tree, icon timeline, view cube, sketch palette. Keys: **E** extrude, **L** line, **R** rectangle, **C** circle, **D** dimension, **H** hole, **Ctrl+Z / Ctrl+Y** undo and redo. Mouse: wheel zooms, middle button pans, Shift + middle button orbits.

- Create a sketch on an origin plane or on a flat face; draw with snapping, or type sizes; dimension lines, circles and arcs (click again to change a value).
- Extrude with a live preview: new body, join, cut (goes into the body), intersect; one side or symmetric; a negative distance flips it.
- Undo, redo, show and hide bodies and sketches from the browser, light and dark themes.

**Not there yet:** arcs, trim, constraints other than dimensions, editing an earlier sketch, fillet and chamfer, save, open and export.
**Tested:** unit tests, tests against the real engine, and real-browser checks of the whole sketch-and-extrude workflow on Linux. **Not tested:** this Windows zip on a Windows PC.

Download `DemonX-Forge-0.2.0-windows-x64.zip`, extract it to `C:\`, run `Start DemonX Forge.bat`. See `READ ME FIRST.txt` inside.
