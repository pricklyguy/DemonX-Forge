# DemonX Forge 0.6.0

Edges you can click: Fillet and Chamfer on bodies.

- **Fillet (F) and Chamfer** in the SOLID tab, MODIFY group. Hover an edge (it turns amber), click to pick it, click again to drop it. Type a size; the part shows the result while you type. OK or Enter keeps it, Cancel or Esc removes it. One undo step.
- A fillet follows edges that continue smoothly, so one pick on a rounded plate rounds the whole outline.
- Edges hidden behind the part cannot be picked.
- A size that is too big is refused with the engine's reason ("the largest radius that fits is 10 mm") and the part is left alone.
- Fixed: Cancel in the Extrude or Fillet dialog could leave the preview behind if it was pressed at the wrong moment.

**Not there yet:** press/pull, shell, revolve, patterns, editing a fillet from the timeline, DXF of a face, STEP import.
**Tested:** unit tests (68) and six real-browser checks against the real engine on Linux. **Not tested:** this Windows zip on a Windows PC.

Download `DemonX-Forge-0.6.0-windows-x64.zip`, extract it to `C:\`, run `Start DemonX Forge.bat`.
